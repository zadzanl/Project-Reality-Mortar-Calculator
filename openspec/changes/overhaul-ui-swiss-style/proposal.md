# Overhaul UI to Swiss Style

## Why

The calculator UI has grown organically across several changes (dark mode, contour display, opening flow) and it shows: duplicated hint text, inline styles fighting the stylesheet, a duplicated `.theme-toggle` CSS block, runtime DOM surgery (`restructureToolShell()` in `app.js`) rebuilding the layout that the template should have described, and a generic "dark admin panel" look. The user wants a deliberate visual identity — Swiss / International Typographic Style with a military-milsim flavor — and a simplification pass to remove redundant controls and labels.

Full redundancy audit: `artifacts/research-ui-redundancy-audit.md`.

## What Changes

**Design system (CSS):**
- New design-token layer in `styles.css`: 8px spacing base unit, 1px hairline rules instead of cards/shadows, square corners, a deliberate typographic scale, and a reduced palette.
- Palette: paper off-white / near-black monochrome base, **olive drab as the single primary accent** (Calculate button, active tab, focus rings), **dark red reserved semantically** for target marker, out-of-range, and errors. Blue retained for the mortar marker. Status colors (in-range / extended / out-of-range) become muted military-toned variants. WCAG AA contrast maintained (>= 4.5:1 body text, >= 3:1 controls).
- Both themes restyled: light = paper off-white, dark = **pitch black `#000000`** backgrounds (user decision; OLED-friendly, contrast only improves). Theme toggle, `pr_theme_mode` localStorage key, and dark-default behavior are unchanged.

**Typography:**
- Vendor Inter (woff2, OFL license) into `calculator/static/fonts/` — weights 400/500/700/800 only. `@font-face` with system fallback stack. No CDN, no new JS dependencies.

**HTML restructure (`index.html`):**
- Move the intended tool-shell structure into the template; reduce or remove runtime DOM reparenting in `app.js`.
- **Merge the Coordinates and Firing Solution panels into ONE left side panel** with two collapsible `<details>` sections: "Firing Solution" (expanded by default) and "Coordinates" (collapsed by default). The map fills the remaining width.
- Remove all inline styles; replace with semantic classes.
- Merge the two duplicated marker-placement hints into one concise hint.
- Consolidate the height-offset help (tooltip + visible tip say the same thing).
- Group the layer checkboxes (Show Grid / Terrain / Contour) under one "Map layers" group.
- Unify loading/status messaging ("Loading maps...", "Ready to calculate" vs JS reset text, map overlay) into one truthful state model.
- **KEEP the Map Size override** in the header — map metadata is not reliable enough to remove manual override. Restyle it and relabel "Auto (Can be mistaken)" to "Auto (from metadata)".

**Map chrome:**
- Restyle Leaflet zoom controls, attribution, and popups to the design system.
- Restyle PR grid labels and the range-circle color to the palette.
- Replace default Leaflet teardrop pins with custom `divIcon` markers: filled blue dot (mortar) and dark-red geometric crosshair (target).

**Opening Flow tab:**
- Restyle only. No structural or ID changes to flow controls — the active change `add-opening-flow-simulator` owns that area. Coordinate before merging.

**Bug fixes folded in (found during audit):**
- Map loading overlay never reappears on subsequent map loads after the first success.
- Remove the duplicated `.theme-toggle` CSS block and dead pre-restructure panel CSS.

## Impact

**Modified files:**
- `calculator/templates/index.html` — restructure shell, remove inline styles, merge hints
- `calculator/static/css/styles.css` — new design system, both themes, map chrome
- `calculator/static/js/app.js` — reduce/remove `restructureToolShell()` DOM surgery, fix loading-overlay bug, unify status text
- `calculator/static/fonts/` — NEW: vendored Inter woff2 + OFL license file

**Spec deltas:** `calculator-ui` (added design-system, typography, and map-chrome requirements; layout requirement reconciled with the implemented shell).

**No changes to:**
- Ballistics math, physics constants, coordinate system
- Flask server, map processing pipeline
- Opening Flow logic (`js/flow/*`)
- Any load-bearing element IDs (full list in the audit artifact) — JS queries by ID, so IDs are frozen
- `www/` (regenerated by `build-android.bat` after implementation)
